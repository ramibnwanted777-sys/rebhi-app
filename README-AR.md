# تطبيق "ربحي" — مشروع Android جاهز (Capacitor)

## ماذا يوجد في هذا المجلد؟
- `www/index.html` — نفس تطبيق الويب (تسجيل، ألعاب، محفظة، سحب، لوحة إدارة سرية).
- `android/` — مشروع أندرويد كامل جاهز للفتح مباشرة في Android Studio.
- الأيقونة مضبوطة مسبقًا في كل الدقات (mdpi → xxxhdpi) + الأيقونة التكيّفية (Adaptive Icon).
- كود AdMob مربوط فعليًا:
  - App ID: `ca-app-pub-9018433497633458~6991878742`
  - Rewarded Ad Unit ID: `ca-app-pub-9018433497633458/4075282810`
- اسم التطبيق: **ربحي** — معرف الحزمة (Package ID): `dz.rebhi.app`

## كيف تبني ملف APK؟

0. **مهم جدًا (خطوة أولى إجبارية):** افتح Terminal/cmd داخل هذا المجلد (مجلد `rebhi-app`) ونفّذ:
   ```
   npm install
   ```
   هذا يحمّل مكتبات Capacitor وإضافة AdMob اللي يحتاجها مشروع أندرويد للبناء (تم حذف مجلد node_modules لتصغير حجم الملف المرسل لك).
1. ثبّت [Android Studio](https://developer.android.com/studio) (مجاني).
2. افتح Android Studio → **Open** → اختر مجلد `android` بالضبط (وليس المجلد الأب).
3. انتظر حتى ينتهي Gradle Sync تلقائيًا (أول مرة قد تأخذ عدة دقائق لتحميل الاعتماديات).
4. من القائمة العلوية: **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
5. بعد الانتهاء، اضغط الإشعار الذي يظهر بالأسفل **locate** لإيجاد ملف الـ APK الناتج (عادة في `android/app/build/outputs/apk/debug/`).
6. انسخ الـ APK لهاتفك أو ثبّته مباشرة عبر المحاكي (Emulator) داخل Android Studio لتجربته.

> ملاحظة: هذا الـ APK (Debug) صالح للتجربة والتثبيت اليدوي فقط. لنشره في Google Play لاحقًا، تحتاج بناء نسخة **Release موقّعة (Signed)** — Android Studio يوفر معالج جاهز لهذا: **Build → Generate Signed Bundle / APK**.

## الدخول السري للوحة الإدارة
لا يوجد أي زر ظاهر لدخول الأدمن في الواجهة. للدخول:
- في شاشة تسجيل الدخول، اضغط على أيقونة العملة (الشعار) أعلى الشاشة **5 مرات متتالية خلال 3 ثوانٍ**.
- ستظهر شاشة دخول المدير. البيانات الحالية (غيّرها من الكود قبل النشر):
  - البريد: `admin@rebhi.dz`
  - كلمة السر: `Admin@2026`

⚠️ **هذه البيانات لا تزال داخل كود الواجهة (JavaScript) ويمكن استخراجها من أي شخص يفحص ملفات الـ APK بأدوات فك الحزم (APK Decompiler).** إخفاء الزر يمنع "الاكتشاف العرضي" فقط، وليس حماية حقيقية. الحل الصحيح النهائي هو نقل تسجيل دخول الأدمن بالكامل إلى سيرفر خلفي (Backend) حيث لا تُرسل كلمة السر مطلقًا داخل كود يصل لجهاز المستخدم.

## قبل النشر الفعلي — أشياء يجب تعديلها
1. غيّر `ADMIN_EMAIL` و`ADMIN_PASSWORD` داخل `www/index.html` (وأعد `npx cap copy android`).
2. أضف سياسة خصوصية منشورة على رابط عام (Google تطلبها إجباريًا لأي تطبيق فيه إعلانات وحسابات مستخدمين).
3. انتقل من `window.storage` (تخزين تجريبي) إلى قاعدة بيانات حقيقية (Firebase مثلاً) قبل إطلاق التطبيق للجمهور — راجع النقاش السابق حول هذا الموضوع.
4. اختبر إعلان AdMob الحقيقي جيدًا؛ في أول أيام حساب AdMob جديد قد لا تظهر إعلانات حقيقية دائمًا (فترة تهيئة طبيعية من جوجل).
